# 🎮 Sistema de Gerenciador de Games

Sistema para gerenciar **jogadores**, **times** e **pontuações** de games de forma simples e organizada.

---

## 🎯 Objetivo

Centralizar o gerenciamento de competições e partidas de games, permitindo:
- Cadastrar novos jogadores
- Formar e gerenciar times
- Registrar e atualizar pontuações
- Acompanhar o desempenho de cada jogador e time

---

## ✨ Funcionalidades

- ✅ **Cadastro de Jogadores** — adicione novos jogadores com nome, apelido e time
- ✅ **Gerenciamento de Times** — crie, edite e organize times
- ✅ **Registro de Pontuações** — insira a pontuação de cada jogador ou time
- ✅ **Atualização de Pontuações** — edite pontuações já registradas
- ✅ **Novos Jogadores** — adicione jogadores a qualquer momento
- ✅ **Novas Pontuações** — registre novas rodadas/partidas
- ✅ **Listagem Geral** — visualize todos os jogadores, times e pontuações

---

## 🗂️ Entidades do Sistema

| Entidade | Descrição | Atributos |
|----------|-----------|-----------|
| **Jogador** | Pessoa que participa das partidas | Nome, apelido, time, pontuação |
| **Time** | Grupo de jogadores | Nome do time, jogadores, pontuação total |
| **Pontuação** | Registro de pontos por partida | Jogador/Time, pontos, data |

---

## 🕹️ Como Usar

1. Abra o arquivo `index.html` no navegador.
2. **Cadastre os jogadores** informando nome, apelido e time.
3. **Monte os times** com os jogadores cadastrados.
4. **Registre as pontuações** de cada partida.
5. **Atualize** pontuações conforme novas partidas acontecerem.
6. **Consulte** a listagem para acompanhar o ranking.
